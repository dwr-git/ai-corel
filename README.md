# AI-Corel

Векторный редактор уровня CorelDRAW и Illustrator прямо в браузере — со встроенным помощником
на вашей собственной локальной модели. Помощник подсказывает, где что находится, и умеет сам
рисовать и менять объекты: фигуры, текст, цвета, выравнивание, обработку контуров.

**Установить на сервер:** [studio/README.ru.md](studio/README.ru.md) — скачать zip из
Releases, распаковать, положить папку. Ничего компилировать не нужно.

## Что здесь добавлено к исходному редактору

- **Помощник** (`studio/`): панель справа от редактора, режимы «Совет» и «Сделай»,
  быстрая строка (Ctrl+Shift+Пробел), видит экран (мультимодальная модель), каждое действие можно отменить.
  Сервер помощника — один PHP-файл, работает через `auth.php`, `config.php` и Ollama вашей системы;
  пока модель думает, он не даёт соединению «заснуть».
- **Самопроверка загрузки** (`studio/web/loader.js`): видно, сколько скачано, а если запуск не удался —
  какой файл не пришёл и почему.
- **Неоморфные светлая и тёмная темы и фирменная тема.**
- Интерфейс по умолчанию на русском; полностью автономная работа — всё грузится из своей папки,
  папку можно называть как угодно.
- Сборки с номерами: каждая — отдельный выпуск в Releases, что нового — в [studio/CHANGES.ru.md](studio/CHANGES.ru.md).

## Основа

Это изменённая версия [VectorCraft](https://github.com/storytold/vectorcraft) от команды ArtCraft —
открытого векторного редактора, написанного с нуля на Rust (фигуры и контуры, перо, текст, градиенты,
слои, монтажные области, обработка контуров, эффекты; SVG, PDF, AI, EPS). Исходное описание проекта —
[docs/README-upstream.md](docs/README-upstream.md).

## Сборка

GitHub Actions собирает готовую папку на каждое изменение ветки `main`
([.github/workflows/studio.yml](.github/workflows/studio.yml)) и выкладывает zip в Releases
как «Сборка N — дата». Локально (нужны Rust, trunk и цель wasm32): `studio/build/package.sh`.
