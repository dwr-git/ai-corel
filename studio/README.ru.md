# AI-Corel — установка на сервер

Векторный редактор в браузере (как CorelDRAW или Illustrator) со встроенным помощником на вашей локальной модели.
На сервере нужны только **nginx + PHP + Ollama** — то, что у вас уже есть. Ничего компилировать не нужно.
Редактор полностью автономный: всё загружается из его папки, интернет и сторонние сайты не нужны.

## Установка (5 минут)

1. **Скачайте готовую сборку.** GitHub → репозиторий `ai-corel` → справа **Releases** →
   верхняя «Сборка N — дата» (с пометкой Latest) → файл `ai-corel-build-N-ГГГГ-ММ-ДД.zip`.
   У каждой сборки свой номер и описание «что нового» (то же — в `CHANGES.ru.md`).
   Какая сборка стоит у вас, видно в шапке панели помощника: «Модель: … · сборка N».
2. **Распакуйте** — внутри одна папка `ai-corel`.
3. **Положите её на сервер** рядом с остальными приложениями: `/app/src/ai-corel/`.
   Папку можно назвать как угодно и переименовать потом — все пути внутри относительные.
   Помощник сам найдёт ваш `auth.php` на два уровня выше (`/app/src/auth.php`)
   и через него — `config.php`, `.env`, адрес Ollama и модель.
4. **nginx** — помощнику нужны большие запросы (снимок экрана) и долгое ожидание модели:
   `client_max_body_size 20m;` и `fastcgi_read_timeout 200s;` для `api/assistant.php`
   (готовый пример — `nginx.conf.example`; правила в нём не зависят от имени папки).
   Если у сервера эти значения уже больше (например, `client_max_body_size 999M` на весь сервер), ничего менять не нужно.
5. **Откройте** `https://ваш-домен/ai-corel/` — войдите в систему, если ещё не вошли.
   Справа появится панель «Помощник».

Обновление — то же самое: скачать новый zip и заменить папку. Свой `studio/config.js`
перед заменой лучше сохранить.

## Что внутри папки

| Путь | Что это |
|---|---|
| `index.html` | Страница редактора |
| `app/` | Сам редактор (WebAssembly, сжат и разрезан на части) |
| `studio/loader.js` | Показывает ход загрузки и, если что-то не так, какой файл не пришёл и почему |
| `studio/` | Панель помощника: `studio.js`, `studio.css`, `ru-labels.json`, `version.json` |
| `studio/config.js` | **Настройки панели** — можно править прямо на сервере |
| `api/assistant.php` | Помощник: проверяет вход, отправляет запрос в Ollama |
| `api/settings.php`, `api/tools.php` | Внутренние настройки и список действий помощника |

## Форматы

Открывает: SVG и SVGZ, PDF, AI, EPS, DXF, EMF/WMF, PSD, картинки (PNG, JPEG, WebP, GIF, TIFF), файлы Affinity.
Сохраняет и экспортирует: собственный формат, SVG, PDF, EPS, AI (совместимый с PDF), PNG, JPEG, WebP.
Файлы CorelDRAW (`.cdr`) редактор пока не открывает — сохраните их в CorelDRAW как SVG, PDF или EPS.

## Настройки в `.env` (необязательно)

По умолчанию помощник берёт всё из вашей системы. Переопределить можно так:

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `AI_COREL_MODEL` | Модель помощника (нужны картинки и tools) | `GLOBAL_MODEL` |
| `AI_COREL_OLLAMA_URL` | Адрес Ollama или шлюза | `OLLAMA_IP:OLLAMA_PORT` |
| `AI_COREL_CONTEXT` | Размер контекста | `GLOBAL_MODEL_CONTEXT` или 32768 |
| `AI_COREL_TIMEOUT` | Сколько секунд ждать модель | 180 |
| `AI_COREL_MAX_TOKENS` | Длина ответа | 2048 |
| `AI_COREL_AUTH_FILE` | Путь к `auth.php`, если папка лежит не в `/app/src/` | ищется автоматически |
| `AI_COREL_ALLOW_ANON` | `1` — без входа (только для проверки!) | выключено |

Запросы помечаются для шлюза как `ai-corel` через ваш `enrichLLMPayload()`.

## Как работает помощник

- **Совет** — объясняет, где найти функцию и что выставить. Ничего не меняет.
- **Сделай** — сам рисует и меняет объекты: находит нужную команду, рисует фигуры и текст,
  красит, выравнивает, объединяет контуры, открывает диалоги и нажимает OK, смотрит на результат.
  Каждое действие видно в ленте, у каждого есть кнопка «Отменить»; всё отменяется и Ctrl+Z.
  Удаление, закрытие и сохранение — только после вашего «Разрешить».
- **Быстрая строка — Ctrl+Shift+Пробел** (или кнопка-молния в шапке панели): поле внизу над холстом,
  ответ всплывает над ним, вся история — в панели.
- **Глаз** рядом с полем ввода — показывать ли помощнику экран (снимок уходит только на ваш сервер).
- **Домик** справа в верхней строке редактора — на уровень вверх, на ваш сайт (`homeUrl` в `studio/config.js`).
  Слева, рядом с меню, — значок сетки: стартовый экран редактора со списком недавних файлов.
- **Палитра** рядом с домиком — список тем: Фирменная, Неоморфная светлая, Неоморфная тёмная, затем остальные.
  Панель помощника переключается вместе с редактором; выбор запоминается.
- Пока модель думает, сервер помощника раз в 10 секунд отправляет пустой пробел, чтобы роутер,
  VPN или прокси не оборвали «молчащее» соединение.

## Если что-то не работает

| Признак | Что проверить |
|---|---|
| Редактор не запускается | Под полосой загрузки написано, какой файл не пришёл и почему. Чаще всего: папка скопирована не целиком, или правило сервера отдаёт вместо файлов другую страницу |
| В панели «Нужно войти в систему» | Вход в вашу систему в этом же браузере и на этом же домене |
| «Не найден auth.php системы» | Задайте `AI_COREL_AUTH_FILE` в `.env` |
| «Сервер помощника ответил не JSON» | PHP не обрабатывает `api/assistant.php` — проверьте блок PHP в nginx |
| Ошибка 413 | `client_max_body_size 20m` (пункт 4) |
| Ошибка 504 / ответ обрывается | `fastcgi_read_timeout 200s` (пункт 4) |
| «Сервер оборвал соединение» | Посмотрите `error.log` nginx в момент запроса |
| «Модель не умеет вызывать инструменты» | `AI_COREL_MODEL` с поддержкой tools |
| «Модель не принимает картинки» | Выключите «глаз» или укажите мультимодальную модель |

Проверка помощника без панели: откройте `https://ваш-домен/ai-corel/api/assistant.php` —
должно показать `{"ok":true,"model":"…"}`.

## Для разработчика

- Сборку делает GitHub Actions (`.github/workflows/studio.yml`) на каждое изменение ветки `main`.
- Редактор управляется со страницы через `window.vectorcraft` (`apps/vectorcraft-web/src/api.rs`):
  `request(метод, параметры)`, `execute(команда, параметры)`, `commands()`, `inspect()`, `screenshot()`, `openFile(имя, байты)` —
  те же методы, что в `docs/control-protocol.md`. В консоли браузера: `await aicorel.call('ui.inspect')`.
- Панель: `studio/web/`, сервер помощника: `studio/api/`, сборка папки: `studio/build/package.sh`.
